# Christopher Grant

I build practical tools for Spark, streaming data, and observability.

## Selected projects

- [LakebaseForeachWriter](https://github.com/christophergrant/lakebase-foreachwriter) — stream PySpark rows to Lakebase or PostgreSQL.
- [spark-otel](https://github.com/christophergrant/spark-otel) — OpenTelemetry for Spark and Databricks workloads.
- [Databricks Hot Restart](https://github.com/christophergrant/databricks-hotrestart) — redeploy Structured Streaming jobs with a short handoff.
- [hydro](https://github.com/christophergrant/hydro) — Python extensions for Spark and Delta Lake.
